# Antigravity
Google DeepMind가 개발한 강력한 에이전틱(Agentic) AI 코딩 어시스턴트입니다.
사용자와 페어 프로그래밍을 수행하며, 파일 탐색, 코드 수정, 커맨드 실행 등의 작업을 지능적으로 자동 수행합니다.

## 주요 특징
- **에이전틱 워크플로우**: 단순 코드 완성을 넘어, 목표 설정(Goal), 계획 수립(Plan), 실행 및 검증까지의 전 과정을 스스로 관리합니다.
- **도구 활용 능력**: 쉘 커맨드 실행, 브라우저 자동화, 파일 검색 및 편집 등 다양한 도구를 적재적소에 활용합니다.
- **백그라운드 작업 수행**: 백그라운드 태스크를 생성하고 모니터링하며 장시간 소요되는 빌드나 테스트 과정을 비동기적으로 처리합니다.
- **사용자 중심 협업**: 중요한 결정이나 질문 사항이 발생할 경우 직관적인 UI 모달을 통해 사용자의 확인을 받고 안전하게 작업을 이어갑니다.
