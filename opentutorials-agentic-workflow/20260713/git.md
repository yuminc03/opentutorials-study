# Git
분산 버전 관리 시스템(DVCS)으로, 프로젝트의 소스 코드 변경 사항을 체계적으로 기록하고 관리하는 도구입니다.

## 주요 특징
- **분산 버전 관리**: 중앙 서버에 의존하지 않고 개발자 개개인이 로컬에 전체 저장소 이력을 복제하여 독립적으로 작업할 수 있습니다.
- **가지치기와 병합(Branching and Merging)**: 여러 작업을 동시에 진행할 수 있도록 브랜치를 생성하고, 작업 완료 후 안전하게 병합하는 기능을 제공합니다.
- **이력 추적**: 파일의 추가, 수정, 삭제 내역을 커밋 단위로 기록하여 언제든지 과거의 특정 시점으로 되돌릴 수 있습니다.
- **협업 지원**: 원격 저장소(GitHub, GitLab 등)를 통해 여러 팀원이 동시다발적으로 코드를 공유하고 협업할 수 있는 기반을 제공합니다.
