# 커스텀 커밋 스킬 작동 가이드
사용자가 `/commit` 명령을 전송했을 때 에이전트는 아래 절차에 따라 작업을 수행합니다.

## 1단계. 변경 사항 확인
- 에이전트는 현재 Git 스테이징 영역에 있는 파일과 변경 내역을 확인합니다.
- `git status` 및 `git diff --cached` 명령을 통해 커밋할 대상이 있는지 조회합니다.
- 스테이징된 변경 사항이 없으면 사용자에게 `git add`가 필요함을 안내합니다.

## 2단계. 커밋 메시지 생성
- 다음 규칙에 맞춰 커밋 메시지를 자동으로 구성합니다.
- **제목(첫째 줄)**: 변경 사항을 명확히 설명하는 1문장 요약
- **공백(둘째 줄)**: 비어 있는 행
- **본문(셋째 줄 이후)**: 수정 목적, 구체적인 수정 내용 등을 비교적 길고 상세하게 서술
- **끝맺음(본문 마지막)**: 반드시 본문 맨 마지막 부분에 "화이팅"을 포함

## 3단계. 사용자 검사 요청
- 생성된 커밋 메시지 전체를 사용자에게 보여줍니다.
- 사용자가 해당 메시지로 커밋하기를 원한다면 `y`를 입력하도록 요청합니다.

## 4단계. 최종 커밋 실행
- 사용자가 `y` 혹은 `Y`를 입력하는 즉시 Git 커밋을 실행합니다.
- 커밋이 성공하면 결과를 리포트합니다.
